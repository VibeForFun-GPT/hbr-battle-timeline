使用说明

  1. 实时模式：选择游戏窗口，点击开始后切回游戏。在第一回合选招前开始；结束时按 Ctrl + Alt + E 或返回此页点「结束并生成行动轴」。
  2. 游戏离开前台或最小化时暂停取新画面；保持游戏完整可见。结束后自动识别并生成图表，捕获素材可回看，不含 Audio。
  3. 录像模式：点击「导入录像」，选择视频并填写战斗开始时间。有边框时使用「画面校准」。
  4. 默认自动匹配角色头像与 HBR Quest 图库。首次下载需要联网，缓存后可离线识别。名字不确定时保留 Placeholder；在「队伍与 Skill 简写」查看候选或自行填写，也可给已有行动轴自动补全名字。手动名字优先保留。
  5. 任意 Skill 都保留 OCR 文本。点击黄色行修正完整名称和简写；同一角色相同 Skill 可同步修改。保存后导出 PNG、Excel、CSV、HTML、JSON 或 ZIP。

前置 OD 在该 Normal Turn 确认前发动；后置 OD 在确认后发动。Skill 产生的额外行动标为「追加」。

剪辑跳过选招、头像遮挡或切换窗口期间的遗漏需要核对。日文 UI 需要替换 OCR Model；默认 Model 用于中文与 English。
